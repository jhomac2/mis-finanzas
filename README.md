# 🚀 SmartFin Pro — Sistema de Contabilidad Personal & Fintech Web

**SmartFin Pro** es una aplicación web interactiva, moderna y de alto rendimiento diseñada para la gestión integral de finanzas personales, presupuestos, control de deudas, análisis multicuenta y proyecciones financieras. Desarrollada con un enfoque *Mobile-First* y una interfaz vanguardista estilo *Dark Neon / Glassmorphism*.

Este proyecto ha sido diseñado como una solución 100% privada, eficiente y de costo cero en infraestructura, destacando buenas prácticas de desarrollo web, experiencia de usuario (UX) e ingeniería de software para el sector Fintech.

---

## 🏛️ Arquitectura y Tecnologías
* **Frontend:** HTML5 Semántico, Tailwind CSS (Design System / Dark Mode), JavaScript (ES6+ Vanilla).
* **Visualización de Datos:** Chart.js (Gráficos interactivos de Donut, Barras y Líneas de flujo).
* **Iconografía & UI:** Lucide Icons / Canvas-Confetti (Micro-interacciones).
* **Persistencia de Datos:** `LocalStorage` del navegador (Arquitectura *Client-Side Only* para privacidad absoluta).
* **Despliegue:** GitHub Pages (Single-Page Application).

---

## 🔒 Privacidad y Seguridad (Client-Side Storage)
* **Privacidad Total:** Toda la información financiera se almacena exclusivamente en el almacenamiento local (`LocalStorage`) del navegador del usuario.
* **Sin Servidor / Zero-Backend:** No requiere bases de datos centralizadas ni credenciales.
* **Aislamiento por Usuario:** Si compartes el enlace con un tercero, cada navegador mantiene un entorno de datos completamente independiente y seguro.

## ✨ Módulos y Funcionalidades Destacadas

1. **📊 Dashboard Financiero Ejecutivo:**
   - Métricas en tiempo real: Balance Neto, Ingresos vs. Egresos, Deudas y Patrimonio Neto.
   - Gráficos interactivos de desglose por categoría, tendencias históricas y flujo de caja acumulado.

2. **💱 Multimoneda Dinámica:**
   - Selector instantáneo entre Dólares ($ USD), Euros (€ EUR) y Pesos ($ PESOS) con recálculo global de símbolos.

3. **📱 Interfaz Adaptativa & Responsive (Mobile-First):**
   - Menú de navegación inferior estilo aplicaciones bancarias de última generación (Nubank, Revolut).

4. **🏦 Gestión Multicuenta & Transferencias:**
   - Mapeo de saldos en Efectivo, Bancos, Tarjetas y Billeteras Digitales (PayPal, Binance, etc.) con registro de transferencias internas sin distorsionar el P&L.

5. **💳 Control de Tarjetas de Crédito & Pasivos:**
   - Seguimiento de cupos, fechas de corte, compras diferidas ("Cuota X de Y") y semáforos visuales de vencimiento.

6. **🎯 Metas de Ahorro & Fondo de Emergencia:**
   - Alcancías virtuales para trazabilidad de objetivos financieros a corto, mediano y largo plazo.

7. **📈 Estado de Resultados (P&L) & Simulador:**
   - Balance General (Activos vs. Pasivos) y simulación de proyecciones a 6 y 12 meses.

8. **📥 Exportación & Cierre de Período:**
   - Respaldo de datos en JSON/CSV y generación de reportes ejecutivos de Cierre Mensual.

## 💡 Guía de Uso
1. **Configuración Inicial:** Establece tu perfil, moneda principal y correo de contacto para alertas.
2. **Registra tus Cuentas:** Añade tus saldos en efectivo, cuentas bancarias y billeteras digitales.
3. **Control Diario:** Registra ingresos, gastos o transferencias clasificándolos por categoría.
4. **Análisis:** Filtra por mes y año para revisar tu salud financiera a través de gráficos interactivos.
5. **Respaldos:** Descarga copias de seguridad de tu información en cualquier momento.
